# スマホ対応 UI プラン（参考：Google スプレッドシート アプリ）

## 現状（コードから）
- グリッド（`js/grid.js`）は **mouse イベントのみ**（`mousedown` 選択・ドラッグ、`e.detail===2` で編集、`contextmenu`、列幅は `mousedown` リサイズ）→ タッチではほぼ操作不能
- 並べ替えチップ（`main.js`）だけ pointer イベント対応済み
- `@media (max-width:760px)` で設計パネル・コンソールを縦積みにする程度
- メニュー類は `ui.js` の `popover` / `menu` / `ask`（アンカー基準の小さな浮き窓）
- 上部バーに DB・数式バー・Undo/Redo・設計・SQL・⌘K が1行に並ぶ

## 方針
- **同じ DOM を CSS とポインタ判定で切り替える**（スマホ専用画面は作らない）
- 判定は `@media (pointer: coarse)` と画面幅。JS 側は `matchMedia` を1か所（`ui.js`）で持つ
- mouse → **Pointer Events に統一**し、`pointerType==='touch'` の時だけ動きを変える
- PC の操作感は一切変えない

## Google スプレッドシート アプリから取り入れる操作
| 操作 | スマホでの挙動 |
|---|---|
| タップ | セル選択（キーボードは出さない） |
| ダブルタップ / 数式バーのタップ | 編集開始（キーボード表示） |
| 選択セルの角の**ハンドル**をドラッグ | 範囲選択 |
| 行番号・列見出しのタップ | 行・列の選択 |
| 長押し | コンテキストメニュー（切り取り/コピー/貼り付け/削除…） |
| 1本指ドラッグ | スクロール（ネイティブ慣性） |
| ピンチ | 拡大縮小（任意・最後に） |

## 画面構成（幅 ≤ 760px）
```
┌ 上部バー：◆DB名▾ ······ ↶ ↷ ⋮ ┐  ← 設計・SQL・コマンドは ⋮ に集約
├ 数式バー：[A1] 値…（タップで編集）┤
├ シート見出し・チップ（横スクロール）┤
│            グリッド               │
├ 下部：シートタブ（横スクロール）＋ │
└───────────────────────────────┘
編集中：キーボード直上に「✓ 確定 / ✕ / → 次 / ↓ 下 / NULL」の補助バー
```
- メニュー・確認・設計パネルは **ボトムシート**（下から出る全幅パネル）に
- タップ領域は最低 44px、グリッド行は 28px のまま（見出し・ハンドルだけ大きく）
- `visualViewport` でキーボードの高さを取り、補助バーとトーストを持ち上げる

## 実装ステップ（各ステップで PC 回帰を確認してコミット）
1. **基盤**：`ui.js` に `isTouch()`（matchMedia）、`viewport` meta に `interactive-widget=resizes-content`、`touch-action` 整理
2. **グリッド入力を Pointer Events 化**：`onMouseDown`→`onPointerDown`、列幅リサイズも pointer に。マウス時の挙動は現状維持
3. **タッチの選択と編集**：タップ選択／ダブルタップ編集／長押しメニュー（500ms・移動で中止）／タッチ中はスクロール優先
4. **選択ハンドル**：選択範囲の右下に丸ハンドルを描き、ドラッグで範囲拡張（端で自動スクロール）
5. **編集補助バー**：キーボード上に確定・移動・NULL。`visualViewport` で位置合わせ
6. **ボトムシート化**：`popover` に `sheet` モードを足し、タッチ時は自動でそちらに。設計パネルも全画面シートに
7. **上部バー整理**：狭い幅では設計/SQL/⌘K を ⋮ メニューへ。数式バーは2段目に
8. **仕上げ**：コピー/貼り付けはメニューから Clipboard API、FK 選択（`Alt+↓` 相当）をセルメニューへ、ピンチズーム（任意）

## 検証
- Playwright の `devices['iPhone 13']` / `Pixel 7` でタップ・長押し・ドラッグをスクリプト化し、スクリーンショット確認
- PC（マウス・キーボード）の既存操作が変わらないことを毎ステップ確認
