# SQLiteシート

スプレッドシート感覚で SQLite を操作できる、ブラウザだけで動く SQLite クライアントです。
サーバーは不要。データはすべて手元のブラウザに保存されます。

## 特長

- **表で編集** — セルをクリックして値を書き換えると、そのまま `UPDATE` が走ります。
- **3種類のシート**
  | シート | 中身 | 編集 |
  |---|---|---|
  | テーブル | 物理テーブル（作成時に `STRICT` を選べる） | セル・行・列を編集可 |
  | ビュー | `CREATE VIEW` したビュー | 閲覧のみ |
  | クエリ | 任意の `SELECT` の結果 | クエリを書き換え可 |
- **並べ替え・絞り込み** — 列見出しから昇順／降順、漏斗アイコンで条件指定。
- **SQL欄** — GUIでできない操作（インデックス、トリガー、一括更新など）は SQL を直接実行。GUI操作が発行した SQL も履歴に残り、`Ctrl+↑` / `Ctrl+↓` で呼び出せます。
- **NULL と空文字を区別** — `NULL` は薄い文字で表示し、入力時も切り替えで指定できます。
- **複数DB** — DB一覧から作成・名前変更・削除。URLにDB名が入るのでブックマークで直接開けます。
- **書き出し・読み込み** — 普通の `.sqlite` ファイルとしてやり取りでき、他の SQLite ツールでもそのまま開けます。

## 使い方

ES Modules を使うため、ローカルの HTTP サーバー経由で開きます（ビルド不要）。

```sh
python3 -m http.server 8000
# → http://localhost:8000/ を開く
```

COOP/COEP ヘッダーなどの特別な設定は不要です。

## しくみ

- SQLite は公式の [`@sqlite.org/sqlite-wasm`](https://www.npmjs.com/package/@sqlite.org/sqlite-wasm) をメインスレッドで使用（CDN から読み込み）。
- DB は **kvvfs v2** の名前付きストレージに置き、ページの変更を監視して **IndexedDB に自動保存**します。保存操作は不要です。
- 外部キー制約は常に有効（`PRAGMA foreign_keys = ON`）。

## 注意

- **Undo はありません。** 大事なデータは書き出してバックアップしてください。
- 保存は非同期のため、変更直後にタブを閉じると最後の変更が失われることがあります。
- 同じDBは同時に1つのタブでしか開けません（他のタブでは「使用中」と表示）。
- クエリシートは DB の外（IndexedDB）に保存されるため、書き出しには含まれません。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` / `style.css` | 画面と見た目 |
| `main.js` | 起動とルーティング（`#/` = 一覧、`#/db/<名前>` = DB画面） |
| `list.js` | DB一覧画面 |
| `sheet.js` | シート画面（表・SQL欄・履歴） |
| `db.js` | sqlite-wasm と永続化 |
| `ui.js` | ダイアログなどの共通部品 |
| `sqlite-sheet-spec.md` | 仕様書 |
